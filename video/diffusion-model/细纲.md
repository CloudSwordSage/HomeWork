# 细纲：逐镜头脚本

配套文件：`大纲.md`。本文件可直接用于配音、做动画和剪辑。

**使用说明**

- 时间码为成片时间，允许 ±0.5 s 误差；以旁白实际长度为准微调画面停留。
- 旁白字数按汉字计（不含标点），括号内为估算语速。
- "屏幕文字"是上屏字幕或版式文字，与旁白不完全相同，静音观看也能看懂。
- 所有镜头默认 1920×1080、30 fps；竖屏发布时按中心安全区重新排版。
- 成片已按旁白实际时长压缩到 2:21.5；段落标题为成片时间，镜头内部时间码为设计稿，实际以 `remotion/src/data/script.json` 为准。

## S0 钩子｜00:00–00:15.8

**目标**：不出现任何术语，用"噪声里长出猫"制造疑问。

**旁白**（54 字，00:04 起）

> 这只看似从雪花里长出来的猫，没有草图，没有线稿。AI 是从一团随机噪声开始，一步步把它擦出来的。这就是扩散模型。

### 镜头 1｜00:00–00:04｜4 s

- 画面：全屏彩色噪点，缓慢推近，颗粒有轻微闪烁。
- 屏幕文字：无。
- 音效：沙沙声由弱到强，音乐同时进入。
- 制作提示：噪点不要用纯白噪声，混入少量彩色颗粒，观感更接近扩散模型的噪声图。

### 镜头 2｜00:04–00:10｜6 s

- 画面：噪点中先出现模糊色块，再出现猫的轮廓，最后细节浮现。用 8–10 张快照快速切换，模拟采样加速播放。
- 屏幕文字：无。
- 音效：沙沙声逐渐减弱，换成轻微"叮"的清晰感音效。
- 制作提示：每一帧都要保留少量噪声，不要出现"突然变清晰"的跳变。

### 镜头 3｜00:10–00:16｜6 s

- 画面：清晰猫图定格，右侧或下方淡入标题《扩散模型：从噪声里"擦"出一张图》。
- 屏幕文字：扩散模型 Diffusion Model
- 音效：音乐第一次小高潮后回落。
- 制作提示：标题停留至少 3 s，方便观众截图和记忆。

## S1 问题｜00:15.8–00:33.3

**目标**：说明"为什么要拆成很多步"，为前向过程做铺垫。

**旁白**（78 字）

> 生成模型要做的事，是看过大量图片之后，造出一张没见过、但同样真实的新图。难就难在：从随机数一步跳到完整图片，跨度太大。扩散模型的思路，是把这一大步拆成很多小步。

### 镜头 4｜00:16–00:24｜8 s

- 画面：图片网格快速滚动（风景、人物、动物），随后中心生成一张"新"图，旁边浮出问号。
- 屏幕文字：生成模型：造一张没见过的新图
- 音效：翻页般的轻快节奏。
- 制作提示：图片库用 20–30 张缩略图即可，滚动速度不要快到看不清。

### 镜头 5｜00:24–00:34｜10 s

- 画面：左右对比。左侧一条大弧线从"随机数"直接跳到"图片"，弧线标红，写"跨度太大"；右侧同一路径被切成 8 级小台阶，每级都短。
- 屏幕文字：一步到位 → 拆成很多小步
- 音效：左侧配"失败"的低沉音，右侧配逐级上行的短音。
- 制作提示：台阶数量不必与真实时间步一致，画面只表达"多步"；角落标注"示意图"。

## S2 前向加噪｜00:33.3–00:55.8

**目标**：讲清前向过程是固定的、无需学习的。

**旁白**（103 字）

> 先看正向过程。拿一张真实图片，每次只加一点点高斯噪声。刚加几次，还看得出原图；加得越多，细节越少；到最后，就只剩下一片纯噪声。关键在于：每一步都很简单，而且这个过程不需要学习——加多少、怎么加，都是事先定好的。

### 镜头 6｜00:34–00:42｜8 s

- 画面：清晰猫图居中，左上角出现"前向过程 Forward Process"标签；画面右侧出现一条从 0 到 T 的时间轴。
- 屏幕文字：前向过程 Forward Process
- 音效：音乐降为铺底，留出旁白空间。
- 制作提示：时间轴用"t = 0 → T"即可，不必写 1000。

### 镜头 7｜00:42–00:58｜16 s

- 画面：猫图连续加噪。画面下方同步显示噪声强度条；角标显示 t 的增长。最后 2 s 完全变成彩色噪声。
- 屏幕文字：每次加一点噪声 → 纯噪声
- 音效：沙沙声随噪声强度线性增大。
- 制作提示：用真实前向公式生成序列，保证噪声强度单调递增；约 12–16 帧足够，剪辑时每帧 0.8–1.2 s。

### 镜头 8｜00:58–01:07｜9 s

- 画面：噪声画面缩小到左侧，右侧淡入公式；公式下方出现一行小字注释。随后画面切回"固定流程"图标：齿轮 + 锁。
- 屏幕文字：

  $$x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1-\bar{\alpha}_t}\,\varepsilon$$

  注释：任意时刻的加噪图，都能由原图和噪声一步算出
- 音效：公式出现时一声轻"咔"，表示确定、固定。
- 制作提示：公式不朗读，字号保证手机可读；`ε` 用希腊字母，避免显示成方块。画面角落标注"训练可随机抽步数、并行计算"可以省略，留给扩展版。

## S3 反向去噪与训练｜00:55.8–01:36.3

**目标**：全片重点。让观众理解网络输出的是"噪声"，不是图片。

**旁白**（190 字）

> 真正要学的，是反过来走。如果知道每一步混进了什么噪声，把它减掉，图片就会清晰一点。可我们并不知道加了什么噪声。
>
> 于是训练一个神经网络。先给它一张加过噪声的图。再告诉它现在是第几步。让它猜图里混进了什么噪声。猜错了就调整参数，猜对了就继续。用海量图片，随机抽取步数，反复训练。它逐渐学会在各种噪声强度下，判断该往哪个方向去噪。
>
> 同一个网络，处理所有时间步。参数共享，变化的只是输入的时间步。

### 镜头 9｜01:07–01:18｜11 s

- 画面：S2 的加噪序列倒放，箭头反向，标签切换为"反向过程 Reverse Process"。倒放到一半暂停，画面出现问号："该减掉多少？"
- 屏幕文字：反向过程 Reverse Process
- 音效：沙沙声倒放，形成"收束"感。
- 制作提示：倒放速度比正放略快，避免观众以为只是重复上一段。

### 镜头 10｜01:18–01:30｜12 s

- 画面：中央出现网络方块（单色发光）。两个输入箭头进入：左边"带噪图"，右边"时间步 t"；一个输出箭头出来：一张噪声图（雪花纹理，不是清晰图）。
- 屏幕文字：输入：带噪图 + 第几步 → 输出：预测的噪声
- 音效：数据流动的轻微电子音。
- 制作提示：**输出一定要画成噪声**。这是科普视频最常见的错误：把网络输出画成清晰图片。

### 镜头 11｜01:30–01:40｜10 s

- 画面：预测噪声与真实噪声并排，中间出现"差值"；差值反馈到网络，网络内部参数格闪烁；误差条从长变短，重复 3 次。
- 屏幕文字：猜错 → 调整参数
- 音效：每次误差缩短配一个上行短音。
- 制作提示：不需要出现"损失函数""反向传播"等术语；画面表达"对比—修正"即可。

### 镜头 12｜01:40–01:52｜12 s

- 画面：三张不同噪声强度的猫图（轻噪、中噪、重噪）排队进入同一个网络方块，方块不复制、不切换，只在上方显示不同的 t。随后画面拉远，显示"海量图片"缩略图墙。
- 屏幕文字：同一个网络，不同时间步
- 音效：节奏加快，进入 S4 前的小推进。
- 制作提示：务必强调"同一个网络"。可以给网络方块加一个固定编号，三张图输入时编号不变。

## S4 采样生成｜01:36.3–02:07.3

**目标**：把训练好的能力接回"生成"，让观众看到完整闭环。

**旁白**（120 字）

> 训练完成，生成就很直接。从一张纯噪声开始，让模型预测噪声，减掉一点。再预测，再减掉。重复几十到上千次，噪声被一层层剥开，一张全新的图片浮现出来。
>
> 步数可以调。多几步更精细，少几步更快速。所以生成一张图，往往要几秒到几十秒。

### 镜头 13｜01:52–02:00｜8 s

- 画面：纯噪声铺满画面，中央出现时间步 `t = T` 和"开始"。一个"生成"按钮被按下。
- 屏幕文字：采样 Sampling｜从纯噪声开始
- 音效：按钮"咔哒"，随后进入循环节奏。
- 制作提示：这里可以复用 S0 的噪声素材，形成前后呼应。

### 镜头 14｜02:00–02:20｜20 s

- 画面：迭代去噪。展示 6–8 个关键帧（如 t = 800、600、400、200、80、0），每帧下方显示"预测噪声"缩略图和"减去"箭头；画面底部进度条从 100% 走到 0%。猫的轮廓在中段出现，细节在后段补齐。
- 屏幕文字：预测 → 减去 → 再预测（循环）
- 音效：每完成一帧一个轻"滴"，节奏稳定；沙沙声逐渐减弱。
- 制作提示：中段帧要保留明显噪声，不要提前变清晰；每帧旁标 t 值，强化"多步"。

### 镜头 15｜02:20–02:32｜12 s

- 画面：最终猫图定格，旁边浮现"×N 次"的循环图标；随后切到两张对比小图（少步数略粗糙、多步数更精细），标注"快"与"精"。
- 屏幕文字：同一个网络，重复调用｜步数：几十到上千
- 音效：音乐再次抬起，准备收束。
- 制作提示：对比图只做轻微差异，不要夸张成"低质量 vs 高质量"，避免误导。

- 制作提示：这句话是全片唯一允许使用"金句"式排版的地方，停留不少于 3 s。

### 镜头 18｜02:52–02:57｜5 s

- 画面：黑场，保留右下角小字署名/课程信息；如需二维码或参考资料，放在这里，不占用正片。
- 屏幕文字：无（或课程信息）
- 音效：音乐自然收尾，最后 0.5 s 静音。
- 制作提示：不要卡在旁白最后一个字上结束，留出呼吸空间。

## 制作顺序

1. 定主图和加噪序列，先做出 S2、S4 的核心动画。
2. 录旁白，按段落切分并测实际时长。
3. 用实际旁白长度回填每个镜头的停留时间，更新时间码。
4. 合成画面、上字幕、混音。
5. 按下方清单自检，再导出成片。

## 自检清单

- [ ] 成片 ≤3:00，旁白总字数约 620 字，无赶读。
- [ ] 全片只出现 1 个公式，且未朗读。
- [ ] 网络输出画的是噪声，不是清晰图片。
- [ ] 采样过程每一步都保留噪声，没有"一步变清晰"。
- [ ] 全片始终是同一个网络，画面没有暗示"每步一个模型"。
- [ ] 没有"模型记住训练图片""必须一千步"等错误表述。
- [ ] 全程硬字幕，静音观看也能理解主线。
- [ ] 每屏文字不超过 10 个汉字，手机尺寸可读。
- [ ] S3 的旁白留白足够，观众有时间消化"预测噪声"。
- [ ] 片尾留 0.5 s 静音，不卡在最后一个字上。

## 常见翻车点

1. **术语堆砌**：正片不出现"马尔可夫链""变分下界""score matching"，这些留给扩展版或答辩问答。
2. **公式过多**：第二个公式会让非专业观众直接放弃，严格只保留一个。
3. **把去噪画成"滤镜变清晰"**：必须体现"预测噪声 → 减去"的循环，而不是一键美颜。
4. **忽略时间步**：不强调 t 作为输入，观众会误以为一个网络只能处理一种噪声强度。
5. **旁白赶画面**：如果实测旁白超时，优先删 S1 和 S4 的修饰句，不要压缩 S2、S3 的核心解释。

# 《扩散模型：从噪声里擦出一张图》视频大纲

## 一、项目定位

| 项目 | 内容 |
| ---- | ---- |
| 类型 | 科普短视频（课程作业） |
| 成片时长 | 目标 2:28，硬上限 3:00 |
| 受众 | 听说过 AI 画图、但不了解原理的普通观众；不要求数学基础 |
| 观看场景 | 手机竖屏或横屏均可，多数人静音观看，因此全程配字幕 |
| 核心目标 | 看完能用三句话讲清扩散模型在做什么 |

**一句话核心信息**

> 扩散模型把"从随机噪声一步生成图片"这个难题，拆成"反复预测并减去一点点噪声"的许多个小步骤。

**观众看完应能回答的三个问题**

1. 扩散模型有哪两个过程？——前向加噪、反向去噪。
2. 神经网络到底在学什么？——学在任意噪声强度下预测噪声，而不是背图片。
3. 生成时从哪里开始？——从纯噪声开始，迭代几十到上千次，不是从草图开始。

## 二、叙事结构

全片用一只猫的图片贯穿：清晰 → 逐渐加噪 → 纯噪声 → 逐步去噪 → 清晰。观众不需要中途重新建立视觉认知。

| 段落 | 时间码 | 时长 | 作用 | 核心内容 |
| ---- | ------ | ---- | ---- | -------- |
| S0 钩子 | 00:00–00:16 | 15.8 s | 抓住注意力 | 噪声中浮现一张猫图，抛出"没有草图，它是怎么画出来的" |
| S1 问题 | 00:16–00:33 | 17.5 s | 建立动机 | 生成模型要造新图；一步从随机数跳到图片太难，所以拆成小步 |
| S2 前向加噪 | 00:33–00:56 | 22.5 s | 讲清第一个过程 | 每次加一点高斯噪声，最终变成纯噪声；过程固定、无需学习 |
| S3 反向去噪与训练 | 00:56–01:36 | 40.5 s | 全片重点 | 网络输入带噪图和步数，输出预测噪声；用预测误差训练 |
| S4 采样生成 | 01:36–02:07 | 31 s | 收拢原理 | 从纯噪声开始，反复"预测—减去"，图像逐层浮现 |
| S5 总结 | 02:07–02:28 | 21 s | 记忆点 | 三件事：加噪、学去噪、迭代生成；多步简单替代一步困难 |
| 合计 | 00:00–02:28 | 148.3 s | | 硬上限 3:00 内 |

**节奏原则**

- 前 15 秒不出现术语，只给画面和问题。
- S3 是全片唯一需要"停下来想"的部分，语速放慢，画面停留时间加长。
- 每个段落结束时用一帧一句话字幕总结，方便观众跟上。

## 三、视觉方案

**视觉主线**

同一张猫的图片贯穿全片，所有状态变化都用噪点的增减表达，不使用花哨转场。段落之间用"噪声推拉"过渡：上一段画面噪点升高，下一段从高噪点接上。

**三段式色彩语言**

| 元素 | 表现 | 含义 |
| ---- | ---- | ---- |
| 清晰图片 | 正常彩度、锐利 | 真实数据 |
| 噪声 | 彩色雪花颗粒 | 随机性 |
| 神经网络 | 单色发光方块/线条 | 学到的去噪能力 |

**屏幕文字规范**

- 每屏不超过 10 个汉字；术语首次出现给中英对照，如"前向过程 Forward Process"。
- 正片只出现一个公式，放在 S2 结尾的画面角落，小字呈现且不朗读。
- 关键数字（步数、时间步）用角标呈现，不打断旁白。

**公式使用原则**

全片只出现：

$$x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1-\bar{\alpha}_t}\,\varepsilon$$

画面注释："任意时刻的加噪图，都能由原图和噪声一步算出"。
它的作用是解释训练为什么能随机抽步数、并行计算，而不是增加理解负担。其余公式（训练损失、采样均值）一律不上屏，只在讲解文档中保留。

## 四、声音方案

| 项目 | 方案 |
| ---- | ---- |
| 旁白 | 中性、偏慢，整体约 3.4 字/秒；重点句后留 0.4–0.6 s |
| 音乐 | 低频氛围铺底，约 −18 dB；S4 采样段加入缓慢上升的音层 |
| 音效 | 前向段"沙沙"噪声随噪声强度增大；反向段同一音效倒放，形成对称感；S5 收束时音乐留白 0.5 s |
| 字幕 | 全程硬字幕，位置固定在画面下方安全区；数学符号用普通字符，避免字体缺字 |

## 五、准确性约束

制作和配音时必须遵守，避免为了通俗而讲错。

| 容易说错的说法 | 问题 | 本片采用的表述 |
| -------------- | ---- | -------------- |
| "模型把噪声一步步完全去掉" | 每步只去除一部分，且标准采样还会加回少量随机噪声 | "每一步预测噪声并减去大部分，同时做缩放" |
| "模型学习了图片长什么样" | 网络学的是不同噪声强度下的去噪方向，不是存储图片 | "学习在任意噪声强度下预测噪声" |
| "每一步都有一个专门的网络" | 所有步骤共用同一个网络，时间步作为条件输入 | "同一个网络反复使用，只是每次告诉它现在是第几步" |
| "扩散模型必须一千步" | 步数取决于采样器与质量要求，DDIM、蒸馏可少至十几步 | "重复几十到上千次" |
| "它把训练图片记下来再拼出来" | 生成是从学到的分布中采样 | "从纯噪声出发采样出一张新图" |
| "扩散模型就是 Stable Diffusion" | Stable Diffusion 是潜空间扩散的一种具体应用 | "Stable Diffusion 是扩散模型的一种应用"（仅在扩展内容中出现） |

正片不涉及的细节：ELBO 推导、score matching、随机微分方程、无分类器引导。这些放入备用问答，不占用正片时长。

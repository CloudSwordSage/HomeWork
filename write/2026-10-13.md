# 软件需求规格说明书

## 任务1：需求优先级排序

根据用户价值、功能依赖关系和实现成本，对10项候选功能进行优先级排序。

| 排名 | 功能编号 | 功能名称       | 优先级 | 排序理由                                                         |
| ---- | -------- | -------------- | ------ | ---------------------------------------------------------------- |
| 1    | F02      | AI智能问答     | 高     | 系统核心功能，直接满足学生知识问答需求，用户价值最高             |
| 2    | F05      | 课程知识库管理 | 高     | 为AI提供课程知识来源，提高课程问答的准确性和针对性               |
| 3    | F06      | AI作业辅导     | 高     | 解决学生作业中的实际困难，使用频率高，依赖AI问答能力             |
| 4    | F04      | 用户身份认证   | 高     | 利用学校统一身份认证实现安全登录，是用户管理和权限控制的基础     |
| 5    | F10      | 课程选择与切换 | 中     | 支持不同课程场景，便于AI获取对应课程知识                         |
| 6    | F08      | 课程资料溯源   | 中     | 提供AI回答的资料来源，增强答案可信度，依赖课程知识库             |
| 7    | F03      | 智能习题生成   | 中     | 辅助学生巩固知识，但实现成本和内容质量控制难度较高               |
| 8    | F01      | 学习进度管理   | 中     | 帮助学生掌握学习情况，但对核心问答功能的依赖较少                 |
| 9    | F09      | 个性化学习计划 | 低     | 具有一定用户价值，但依赖学习目标、课程安排等信息，开发成本较高   |
| 10   | F07      | 错题诊断分析   | 低     | 有助于针对性学习，但依赖学生作答数据和分析能力，初期实现成本较高 |

### 最重要的3项功能及理由

1. F02：AI智能问答

AI智能问答是系统的核心功能，直接满足学生随时提问、获取知识解释的需求，是产品最主要的用户价值来源。

2. F05：课程知识库管理

课程知识库为AI提供可靠的课程资料，使回答能够结合实际教学内容，减少偏离课程范围和生成错误信息的问题。

3. F06：AI作业辅导

AI作业辅导能够将知识问答扩展到实际学习任务，通过解题思路和分步骤提示帮助学生理解问题，提高系统的实用性。

#### 主要功能依赖关系：

- F05 → F02：课程知识库为课程相关的AI问答提供知识来源。
- F02 → F06：AI作业辅导复用AI问答的自然语言理解与生成能力。
- F04 → F05：教师管理课程资料前需要完成身份认证和权限验证。
- F10 → F02：涉及特定课程的问答需要确定当前课程。

## 任务2：编写符合SRS规范的功能需求

### 需求一：AI智能问答

**ID：** SRS-001

**TITLE：** AI智能问答功能

**DESC：**

- **输入：** 学生通过问答界面输入自然语言问题，单次输入不超过2000个字符。
- **处理过程：** 系统检查输入内容是否有效，调用AI模型理解问题并生成回答。当问题涉及已选课程时，系统应优先检索该课程知识库中的相关内容，将检索结果作为回答依据。
- **输出结果：** 系统在问答界面显示回答文本。当使用课程资料作为依据时，应提供对应资料的引用信息。
- **异常处理：** 当输入为空时，提示“请输入问题”；当AI服务不可用时，提示“服务暂时不可用，请稍后重试”；当课程知识库缺少足够依据时，应提示信息不足，不得编造课程资料来源。

**RAT：** 满足学生在学习过程中随时提出问题并获得知识解释的需求，提高学习效率，降低获取学习帮助的成本。

**DEP：** F05课程知识库管理；涉及特定课程时依赖F10课程选择与切换。

**PRIORITY：** 高

**AC：验收标准**

1. 输入有效问题后，系统能够向AI服务提交问题并显示返回的回答。
2. 输入为空或仅包含空白字符时，系统阻止提交并显示提示。
3. 当课程知识库存在相关资料且回答使用该资料时，系统能够显示对应的资料引用。
4. 当AI服务请求失败时，系统显示错误提示，且界面仍允许用户重新提交问题。
5. 当课程资料不足以支持回答时，系统不得生成虚假的资料引用信息。

### 需求二：课程知识库管理

**ID：** SRS-002

**TITLE：** 课程知识库管理功能

**DESC：**

- **输入：** 具有课程管理权限的教师选择目标课程，上传课程资料文件，或对已有资料执行更新、删除操作。
- **处理过程：** 系统验证用户权限、文件格式和文件大小。对于有效文件，系统提取文本内容并建立知识检索索引；对于更新或删除操作，同步更新知识库中的资料及其索引。
- **输出结果：** 系统显示资料名称、所属课程、处理状态等信息。处理成功的资料可以被对应课程的AI问答功能检索使用。
- **异常处理：** 无权限用户不得修改资料；不支持的文件格式或超过大小限制的文件应被拒绝；文件解析失败时，应显示失败原因，不得将其标记为可用。

**RAT：** 为AI智能问答提供与学校课程相符的知识内容，便于教师持续维护教学资料，提高课程问答的针对性。

**DEP：** F04用户身份认证；为F02智能问答和F08课程资料溯源提供数据支持。

**PRIORITY：** 高

**AC：验收标准**

1. 具有相应权限的教师能够上传PDF、DOCX、TXT格式的文本资料，单文件大小限制为20MB。
2. 文件处理成功后，资料应出现在对应课程的资料列表中，且可以被知识检索功能检索。
3. 教师更新资料后，知识检索应使用更新后的内容，不再返回被替换的旧版本内容。
4. 教师删除资料后，该资料不再出现在课程资料列表和知识检索结果中。
5. 无管理权限的用户尝试修改课程资料时，系统应拒绝操作。
6. 对格式不支持、文件过大或无法解析的文件，系统应显示明确的错误信息。

### 需求三：AI作业辅导

**ID：** SRS-003

**TITLE：** AI作业辅导功能

**DESC：**

- **输入：** 学生在作业辅导界面输入作业题目、已知条件，以及需要帮助的具体问题。
- **处理过程：** 系统检查题目内容是否有效，利用AI模型分析题目要求与已知条件，生成分步骤的解题思路和提示。学生可以针对不理解的步骤继续提问，系统根据上下文提供进一步解释。
- **输出结果：** 系统显示题目分析、解题思路和步骤提示，并支持学生继续追问。
- **异常处理：** 当题目为空时，提示用户补充题目；当条件不足以确定解题方法时，提示学生补充必要信息；当AI服务异常时，显示错误提示并允许重新请求。

**RAT：** 帮助学生理解作业题目、掌握解题方法，减少学习过程中因缺少指导而无法继续完成作业的情况。

**DEP：** F02 AI智能问答；涉及课程知识时依赖F05课程知识库管理。

**PRIORITY：** 高

**AC：验收标准**

1. 学生提交有效作业题目后，系统能够返回与题目相关的解题思路或步骤提示。
2. 当学生询问某个解题步骤时，系统能够结合当前会话中的题目和前序回答进行解释。
3. 当题目缺少必要条件时，系统能够提示需要补充的信息，而不是将不确定的条件当作已知事实。
4. 输入空白题目时，系统应阻止提交并显示提示信息。
5. 当AI服务请求失败时，系统能够显示失败提示，并允许学生重新请求辅导。

## 任务3：检查需求质量

针对以上3条功能需求，从以下方面进行检查：

| 检查项目         | 检查结果                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 需求描述是否明确 | 已明确功能的输入、处理过程、输出结果和异常情况，避免单独使用“快速”“智能”“友好”等模糊词语作为要求 |
| 功能过程是否完整 | 3条需求均包含输入检查、系统处理、结果输出及异常处理                                              |
| 是否存在需求矛盾 | 未发现直接冲突；作业辅导复用智能问答能力，课程问答使用知识库内容                                 |
| 是否说明依赖关系 | 已通过DEP字段说明主要依赖功能，并区分业务优先级与开发顺序                                        |
| 是否可验证和测试 | 每条需求均提供具体、可执行的验收标准                                                             |
| 是否具有唯一编号 | 使用SRS-001、SRS-002、SRS-003标识，便于后续追踪和维护                                            |

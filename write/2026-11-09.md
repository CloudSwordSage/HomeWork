# 报表日期检查功能的等价类划分测试

## 一、问题分析

某报表处理系统要求用户输入处理报表的日期。合法日期范围是 **2001 年 1 月至 2005 年 12 月**，系统只处理该期间内的报表，超出范围时显示输入错误。

输入日期由年、月共 6 位数字字符组成，前 4 位表示年份，后 2 位表示月份。因此，程序的日期检查功能实际需要校验以下条件：

1. 输入长度必须为 6 个字符；
2. 6 个字符必须全部为数字；
3. 前 4 位表示的年份必须在 2001～2005 之间；
4. 后 2 位表示的月份必须在 01～12 之间。

满足上述条件的输入，其取值等价于 `200101`～`200512` 范围内的所有 6 位数字串，共 5 × 12 = 60 个合法年月。

## 二、等价类划分

按照输入域的有效性，将输入数据划分为有效等价类和无效等价类。无效等价类依据“单缺陷假设”划分，即每个无效用例只违反一条输入规则，避免多个错误相互屏蔽。

| 编号 | 类型 | 等价类描述 | 说明 |
| ---- | ---- | ---------- | ---- |
| V1 | 有效等价类 | 6 位数字，年份为 2001～2005，月份为 01～12 | 即 `200101`～`200512` |
| I1 | 无效等价类 | 输入不足 6 位 | 包括空输入 |
| I2 | 无效等价类 | 输入超过 6 位 | 即使前 6 位合法也属于无效 |
| I3 | 无效等价类 | 长度为 6 但含有非数字字符 | 字母、符号、空格等 |
| I4 | 无效等价类 | 6 位数字，年份合法，月份为 `00` | 月份低于下界 |
| I5 | 无效等价类 | 6 位数字，年份合法，月份为 `13`～`99` | 月份高于上界 |
| I6 | 无效等价类 | 6 位数字，月份合法，年份小于 2001 | 年份低于下界 |
| I7 | 无效等价类 | 6 位数字，月份合法，年份大于 2005 | 年份高于上界 |

说明：

- 年份和月份同时越界的输入（如 `200013`）同时违反多条规则，不属于单一等价类。按单缺陷假设，测试用例设计时只需保证每个等价类被单独覆盖，组合情况可在其他测试方法中补充。
- `000000`、`999999` 一类输入同时违反年份和月份两条规则，不属于单缺陷用例；若要单独验证某一规则，应选择只有一个字段越界的输入，如 `200100`、`200513`、`200012`、`200601`。

## 三、测试用例设计

为每个等价类选取代表性数据。有效等价类除选取一般代表值外，同时选取上下边界和中间值，以便发现边界处理错误；每个无效等价类至少选取一个用例。

| 用例编号 | 输入数据 | 覆盖等价类 | 预期结果 |
| -------- | -------- | ---------- | -------- |
| TC-01 | `200101` | V1（下边界） | 接受，按 2001 年 1 月处理 |
| TC-02 | `200306` | V1（中间值） | 接受，按 2003 年 6 月处理 |
| TC-03 | `200512` | V1（上边界） | 接受，按 2005 年 12 月处理 |
| TC-04 | `20011` | I1（5 位） | 提示输入错误 |
| TC-05 | 空输入 | I1（空串） | 提示输入错误 |
| TC-06 | `2001011` | I2（7 位） | 提示输入错误 |
| TC-07 | `20O101` | I3（含字母） | 提示输入错误 |
| TC-08 | `2001-1` | I3（含符号） | 提示输入错误 |
| TC-09 | `200100` | I4（月份为 00） | 提示输入错误 |
| TC-10 | `200513` | I5（月份为 13） | 提示输入错误 |
| TC-11 | `199912` | I6（年份 1999，月份合法） | 提示输入错误 |
| TC-12 | `200012` | I6（年份 2000，月份合法） | 提示输入错误 |
| TC-13 | `200601` | I7（年份 2006，月份合法） | 提示输入错误 |
| TC-14 | `200612` | I7（年份 2006，月份合法） | 提示输入错误 |

其中 TC-11 与 TC-12、TC-13 与 TC-14 属于同一等价类，保留多个用例是为了分别验证“较早年份”和“紧邻上边界的越界年份”两种情况，可按需精简。

## 四、覆盖情况检查

| 等价类 | 覆盖用例 |
| ------ | -------- |
| V1 | TC-01、TC-02、TC-03 |
| I1 | TC-04、TC-05 |
| I2 | TC-06 |
| I3 | TC-07、TC-08 |
| I4 | TC-09 |
| I5 | TC-10 |
| I6 | TC-11、TC-12 |
| I7 | TC-13、TC-14 |

所有有效等价类和无效等价类均至少被一个测试用例覆盖。

## 五、设计要点

1. **先划分、后选值**：等价类划分关注输入域的分类，测试用例只需从每一类中选取代表值，不必穷举全部输入。
2. **无效类单独覆盖**：按单缺陷假设，一个无效用例只应违反一条规则，否则无法判断程序究竟检出了哪一条错误。
3. **有效类关注边界**：有效等价类内部取值行为应一致，但边界值最容易暴露比较条件写错的问题，因此补充了 `200101` 和 `200512`。
4. **结合边界值分析**：若需要更严格的测试，可在等价类划分的基础上补充 `200012`／`200101`、`200512`／`200601`、`200100`／`200101` 等紧邻边界的用例，进一步验证“小于等于”与“大于等于”的判断是否正确。

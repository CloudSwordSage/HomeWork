# 递推公式

## 一、

$\frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \cdots + \frac{1}{(n-1) \times n}$
附加前提: $n\ge2$, 因为 $n = 1$时, $\frac{1}{0 \times 1}$ 无意义
设原式为$S_n = \frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \cdots + \frac{1}{(n-1) \times n}$
那么从$S_{n-1}$ 到 $S_n$ 只是加了末项$\frac{1}{n(n-1)}$
即递推公式为$S_n = S_{n-1} + \frac{1}{n(n-1)}, n\ge3$
初始状态$S_2 = \frac{1}{2}$

## 二、

$\frac{1}{1} + \frac{1}{7} + \frac{1}{49} + \cdots + \big(\frac{1}{7}\big)^n$

设$q=\frac{1}{7}$, 则原式为$S_n = 1 + q + q^2 + q^3 + \cdots + q^n$
那么$S_{n-1} = 1 + q + q^2 + q^3 + \cdots + q^{n-1}$
我们保留$Sn$的首项1, 对其他项提取公因子, 得到$S_n = 1 + q(1 + q + q^2 + q^3 + \cdots + q^{n-1})$
即$S_n = 1+q S_{n-1}$
代回$q=\frac{1}{7}$, 得到$S_n = 1 + S_{n-1} \times \frac{1}{7} = 1 + \frac{S_{n-1}}{7}$
初始状态$S_0 = 1$

## 三、

$1 + \frac{1}{3} + \frac{1}{5} + \frac{1}{7} + \cdots + \frac{1}{2n-1}$

设原式为$S_n = 1 + \frac{1}{3} + \frac{1}{5} + \frac{1}{7} + \cdots + \frac{1}{2n-1}$
那么从$S_{n-1}$ 到 $S_n$ 只是加了末项 $\frac{1}{2n-1}$
即递推公式为$S_n = S_{n-1} + \frac{1}{2n-1}$
初始状态$S_1 = 1$

## 四、
> 书中公式有误, 最后一项必须为$(-1)^{n-1}\frac{1}{3n-2}$才能出现符号交替, 若按原文的$(-1)\frac{1}{3n-2}$来看, 应该均是负号, 不应该出现加法.

$1 - \frac{1}{4} + \frac{1}{7} - \frac{1}{10} + \cdots + (-1)^{n-1}\frac{1}{3n-2}$

设原式为$S_n = 1 - \frac{1}{4} + \frac{1}{7} - \frac{1}{10} + \cdots + (-1)^{n-1}\frac{1}{3n-2}$
那么从$S_{n-1}$ 到 $S_n$ 只是加了末项 $(-1)^{n-1}\frac{1}{3n-2}$
即递推公式为$S_n = S_{n-1} + (-1)^{n-1}\frac{1}{3n-2}$
初始状态$S_1 = 1$
